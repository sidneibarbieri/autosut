# Baseline status

The raw-versus-enriched comparison is generated by
`scripts/compare_compilation_arms.py`. It compares readiness, boundary
assignment, platform coverage, and constraint provenance on the same campaign
plan; it does not turn a count into an execution claim.

PentestGPT is tracked as an external baseline, not vendored into this
artifact. Its public implementation is interactive and requires a configured
LLM API. A run is therefore recorded as `unavailable` when no API-backed
configuration is supplied; it must never be represented as zero successes.
When credentials and a compatible benchmark are available, the adapter must
write the same fields as the enriched arm: campaign/step IDs, SUT identity,
interventions, evidence paths, duration, and missingness reason.
